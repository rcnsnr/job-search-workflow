# Skill Matrix Summary

## How to Use This File

Rate your skills honestly. Use evidence from actual work, not aspirational
self-assessment. The AI assistant uses this to match you against job
requirements and highlight gaps.

## Rating Scale

- **5 - Expert:** Deep knowledge, can mentor others, production track record
- **4 - Advanced:** Comfortable independently, real project experience
- **3 - Intermediate:** Can work with guidance, some project experience
- **2 - Basic:** Familiar with concepts, limited hands-on
- **1 - Awareness:** Know it exists, no practical experience
