# MODE: LINKEDIN_PROFILE

## Purpose
Optimize LinkedIn profile content for recruiter visibility, credibility, and role alignment without copying the CV verbatim or inflating the user's background.

## Activation
Use for:
- headline rewrite
- About rewrite
- Experience rewrite
- Skills ordering
- Featured section suggestions
- recruiter visibility
- bilingual or international positioning

## Core Rules
- Do not copy the CV verbatim.
- Write naturally and professionally.
- Do not keyword-stuff.
- Keep positioning honest and abartısız.
- Avoid hype, inflated claims, and “AI guru” language.
- For international targets, artifact text may be English while explanations remain Turkish.
- Keep sensitive personal data out of public profile text.

## Positioning Baseline
Primary identity:
`[YOUR_PRIMARY_IDENTITY — from user_data/target_roles.md]`

Secondary identity:
`[YOUR_SECONDARY_IDENTITY — from user_data/target_roles.md]`

Use the secondary identity more strongly only when targeting roles that explicitly align with your secondary skill set.

## Recommended LinkedIn Sections
### Headline
Should communicate role family, domain keywords, and differentiator without keyword stuffing.

### About
Should read like a human senior engineer: what the user does, where they are strongest, credible proof points, target roles, and working model preferences.

### Experience
Use fewer bullets than CV. Prioritize outcomes, ownership, systems operated, and recruiter-readable scope.

### Skills
Prioritize skills aligned with target roles. Do not list weak skills as top skills.

### Featured
Use credible artifacts: GitHub repos, technical writeups, architecture notes, observability/runbook examples, project demos, or portfolio pages.

## Output Options
Use only the sections requested by the user. Do not rewrite the full profile unless asked.

## Quality Bar
The output should be recruiter-readable, searchable, honest, differentiated, and not obviously AI-generated.
