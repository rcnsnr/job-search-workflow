# MODE: RECRUITER_OUTREACH

## Purpose

Write concise, professional messages for recruiters, headhunters, hiring managers, referrals, follow-ups, and short cover letters.

## Activation

Use for:

- recruiter DM
- hiring manager message
- referral request
- follow-up
- short cover letter
- intro message for B2B/contract roles

## Rules

- Keep messages short, professional, and non-needy.
- Do not overpraise the company.
- Do not exaggerate fit.
- Do not claim experience not supported by CV or user notes.
- For international roles, produce English artifacts by default unless asked otherwise.
- Avoid unnecessary personal data.
- Ask for missing details only if required: recipient name, company, role, or message channel.

## Tone

Preferred tone:

- confident
- specific
- practical
- calm
- not salesy

Avoid:

- "I am very passionate" filler
- generic "perfect fit" claims
- long autobiography
- desperation signals

## Default Output Formats

### Recruiter DM

80-130 words.

### Hiring Manager Message

100-160 words, more technical and role-specific.

### Referral Request

70-120 words, respectful and low-pressure.

### Follow-Up

40-90 words.

#### 14-Day Application Follow-Up Template

Use after submitting an application and receiving no response within 14 days.
Keep it short, specific, and non-needy.

```text
Hi [Name],

I applied for the [Role] role at [Company] two weeks ago and wanted to check in. I remain very interested because [one specific reason]. If there is any additional context I can provide, please let me know.

Best regards,
[YOUR_NAME]
```

When sending to a recruiter or hiring manager, keep the total message under 90 words and reference the role explicitly.

### Short Cover Letter

180-260 words unless user asks shorter.

## Cover Letter Format (MANDATORY)

- Cover letter `.md` file is written as plain prose.
- Markdown markers are FORBIDDEN: `**bold**`, `*italic*`, `## heading`, `` `code` ``, `- bullet`, `1. list`, `> quote`.
- Content must be directly copy/pasteable into email body or ATS form.
- Paragraphs are separated by blank lines.
- Signature is written as plain text (e.g., "Best regards,\n[YOUR_NAME]").
- This rule does not apply to CV/resume files.

## Quality Bar

The message should make the recipient understand the fit quickly without forcing them to read the full CV first.
